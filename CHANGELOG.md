# Changelog

## v0.7.0 — initial public source publication (2026-11-08)

- Desktop interface for the original Montrasio–Valentino (2008) SLIP formulation.
- Rectangular and trapezoidal side-profile geometry calculations.
- Direct, original sprinkler-calculated and imported incremental rainfall modes.
- Derived `K_T=K/L` or manually supplied drainage coefficient.
- Numerical stability table, FS chart, sampled and interpolated threshold reporting.
- One-parameter sensitivity comparison with numerical table and graph export.
- CSV export, PNG graph export, regression tests and Windows build scripts.
- Explicit `m_raw`/capped `m` diagnostic beyond the physical saturation limit.

**Scope:** The experimental sprinkler geometry/wall-interception prototype is not included. No experimental calibration or predictive validation is claimed. A Windows installer release asset has not yet been attached through GitHub Releases.
