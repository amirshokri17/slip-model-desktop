SLIP MODEL DESKTOP v0.7 — WINDOWS INSTALLER BUILD KIT
====================================================

This build uses the ORIGINAL v0.7 SLIP engine, without the experimental
sprinkler-geometry extension. Source calculations are not modified.

REQUIREMENTS ON THE BUILD COMPUTER
- Windows 10 or 11, 64-bit
- Python 3.15, available via: py -3.15 --version
- Inno Setup 6: https://jrsoftware.org/isinfo.php
- Internet connection for downloading Python packages

IMPORTANT: USE A SHORT BUILD DIRECTORY
Extract this project directly to C:\SLIPBuild rather than a long Desktop path.
PySide6 may install files with very long nested names; Windows may reject those
paths when the build folder is deeply nested.

RUN THE BUILD
1. Open Command Prompt in C:\SLIPBuild.
2. Run BUILD_WINDOWS_INSTALLER.bat.
3. The script builds .buildenv and runs the regression tests, then PyInstaller.
4. Inno Setup compiles SLIP_Model_Installer.iss to:
       installer\SLIP_Model_Setup_v0_7.exe
5. If the script reports missing Inno Setup or fails, no final installer exists.
   Look for the first ERROR message; a PyInstaller dist folder is not an installer.
6. The installer is unsigned and can trigger Windows publisher warnings.

VERIFY ON A SEPARATE WINDOWS PC
- Install through the setup wizard (Python not required on target PC).
- Launch from the Start menu and optional desktop shortcut.
- Check reference-model baseline FS at 40 min (approximately 1.64178).
- Test the numerical scenario documented in docs/NUMERICAL_EXAMPLE.md.
- Test CSV import, sensitivity analysis, both PNG exports and uninstall.

DISTRIBUTION
- Upload the final installer to GitHub Releases with its SHA-256 checksum.
- Do not upload .venv, .buildenv, dist, build, or private laboratory files.
- See THIRD_PARTY_NOTICES.txt for PySide6/Qt redistribution requirements.
