**From a geotechnical research paper to a working Windows desktop tool**

I have developed **SLIP Model Desktop v0.7**, an independent Python/PySide6 implementation of the shallow-landslide stability model proposed by **Montrasio and Valentino (2008)**.

The application lets users examine how rainfall, slope geometry, soil properties and initial volumetric water content influence the calculated factor of safety over time. It includes numerical outputs, a stability graph, one-parameter sensitivity analysis, CSV/PNG exports, and a Windows installer.

In a documented **numerical example**, the factor of safety decreases from 12.69 initially to the FS = 1 threshold at approximately 12.53 minutes (graphically interpolated). The software also flags calculations that exceed the model's physical saturation limit.

The original mathematical model is credited to its authors. This is an independent software implementation for learning and research, not an experimentally validated landslide-warning system.

Source code, numerical example, limitations and Windows release: https://github.com/amirshokri17/slip-model-desktop
